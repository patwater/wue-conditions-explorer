ALL DATA IN THIS REPORT IS SIMULATED. It must not be mistaken for real utility records. Planted effects are assumptions written into the generator, not knowledge about real households.

Synthetic SCUBA validation report

Profile default, root seed 20181201, generated 2026-10-26.

What this report answers

Nobody knows the true savings of real households, because the counterfactual usage is never observed. The generator knows each synthetic household's savings only because it planted them. This report therefore asks a narrower question: does matched difference-in-differences recover an effect we planted, in a world with turnover, vacancy, missing rows, drought shocks and selection on conservation attitude, and how robust is that recovery when the planted world changes? The paper's savings figures are estimates, so they anchor the estimated side of the results, not the planted effect.
